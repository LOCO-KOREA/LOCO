# 화면명세서 (GPT 이미지 생성용)

> 근골격계 유해요인조사 보조 앱 · PC(윈도우) 프로그램 · 작성 2026-10-08, 수정 2026-10-12 (실시간 촬영 없음: 사진 여러 장을 올리고 하루 작업시간을 입력하는 방식)
> 이 파일을 GPT에 첨부하고, 아래 「붙여 넣을 프롬프트」를 그대로 보낸다. 참고 이미지 2장(`화면참고_분석결과.png`, `화면참고_결과엑셀.png`)도 함께 첨부한다.

## 붙여 넣을 프롬프트

```
첨부한 「화면명세서_GPT용.md」에 적힌 PC 프로그램 화면을 UI 목업 이미지로 만들어 줘.

규칙
1. 한 번에 한 화면만 만든다. S01부터 시작하고, 내가 "다음"이라고 하면 다음 화면을 만든다.
2. 가로형(1536×1024). 윈도우 PC 프로그램 창 하나가 이미지를 꽉 채운다.
3. 모든 화면에 명세서의 「공통 스타일」을 똑같이 쓴다. 첨부한 참고 이미지 2장의 색과 모양을 따른다.
4. 화면 속 글자는 명세서에서 큰따옴표(" ") 안에 적힌 한국어 문구만 그대로 쓴다. 바꾸거나 늘리거나 다른 글자를 더하지 않는다.
5. 숫자는 명세서의 예시 숫자를 그대로 쓴다.
6. 사람은 실사로 그리지 않는다. 주황색 관절 선과 흰 관절 점으로 그리고, 머리는 단순한 회색 원으로 그린다.
7. 카메라 촬영 화면, 녹화 표시, 웹캠은 그리지 않는다. 이 프로그램은 찍어 둔 사진을 올려서 분석한다.
8. 실제 회사 로고, 상표, 운영체제 로고는 넣지 않는다.
9. 글자가 작아 깨질 것 같으면 글자를 크게 하고, 그래도 어려우면 그 문구를 빼고 무엇을 뺐는지 알려 준다.
```

## 공통 스타일

- **창**: 윈도우 PC 프로그램 창 하나. 모서리를 살짝 둥글게, 테두리는 진한 남색.
- **제목 표시줄**: 진한 남색(#18232F) 띠. 왼쪽에 흰 글씨 "유해요인조사 보조", 그 옆에 화면 이름.
- **탭 줄**: 제목 표시줄 아래 연회색(#E6EBF0) 띠. 탭 7개 "조사", "작업", "사진", "결과", "판정", "내보내기", "설정". 지금 화면의 탭에만 주황 밑줄.
- **바탕과 카드**: 바탕은 아주 밝은 회색(#F2F4F6). 카드는 흰색(#FBFCFD)에 얇은 회색 테두리와 둥근 모서리.
- **강조색**: 주황(#D9661F)은 주요 버튼과 경고에만. '높음' 같은 위험 글자는 진한 주황(#B5521A). '확인 필요'는 연노랑 배경(#F6E2B8).
- **글꼴**: 한글 고딕체. 글자는 크고 또렷하게.
- **사람 그림**: 실사 금지. 주황 관절 선 + 흰 관절 점, 머리는 회색 원.
- **그 밖**: 로고와 상표 없음. 숫자는 아래 예시 그대로.

## S06 분석 결과와 경고 (참고 이미지 「화면참고_분석결과.png」과 같은 구성)

- 탭: "결과"
- 제목 표시줄 오른쪽 연회색 글씨: "사진 21장 · 판별 가능 20장"
- 왼쪽 큰 사진 (진한 남색 바탕)
  - 관절 선으로 그린 사람이 허리를 깊이 굽혀 바닥의 상자를 드는 자세. 머리는 회색 원
  - 왼쪽 위 주황 배지: "REBA 9"
  - 오른쪽 위 연회색 글씨: "가장 위험한 사진 · 8번"
  - 아래 가로 사진 칸 줄: 작은 세로 칸 21개가 한 줄로 이어짐. 7칸은 주황, 1칸은 짙은 회색, 나머지는 연회색. 한 칸에 굵은 흰색 테두리 (대표 사진)
  - 칸 줄 아래 작은 글씨: "주황 = 허리를 20° 이상 굽힌 사진 7장 / 20장 = 35%"
- 오른쪽 카드 3개 (위에서 아래로)
  1. 작게 "가장 높은 점수" / 큰 진한 주황 글씨 "REBA 9 · 높음" / 작게 "목 2 · 몸통 4 · 다리 2 · 위팔 3 · 무게 15kg"
  2. 작게 "4호 · 허리 20° 이상 굽힘 · 기준 하루 총 2시간" / 큰 진한 주황 글씨 "2.1시간" 옆에 작게 "= 사진 표본 35% × 하루 6시간" / 가로 막대 (주황으로 반쯤 채움, 가운데에 검은 세로선) / 막대 아래 작은 회색 글씨 "각도 기준: 고용노동부 해설"
  3. 경고 상자 (연주황 바탕, 주황 테두리): 작게 "경고" / 굵게 "부담작업 4호 기준(하루 총 2시간)을 넘습니다" / 작게 "AI 작성 · 상자를 허리 높이 선반에 두면 굽힘을 줄일 수 있어요"

  - "4호 해당 (초안)" / "허리 20° 이상 굽힘 35% × 하루 6시간 = 2.1시간"
  - "9호 해당 (초안)" / "무릎 아래에서 10kg 이상 들기 하루 300회"

  - "1호 입력 필요" (연회색 배경) / "키보드·마우스 작업 시간을 넣어 주세요"
