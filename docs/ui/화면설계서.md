# LOCO MVP 화면설계서

## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 제품 | LOCO MVP · 유해요인조사 작업 공간 |
| 화면 수 | 8개 화면 + 전체 미리보기 |
| 캔버스 | 1440 × 1024px |
| 기준 파일 | `svg/`의 편집 가능한 SVG와 `png/`의 화면 미리보기 |
| 사용자 | 사업주, 조사자, 작업자·참여자 |

이 문서는 현재 수정된 화면 디자인을 기준으로 화면의 목적, 주요 구성, 상태 및 공통 시각 규칙을 설명한다. 각 화면은 예시 데이터가 포함된 MVP 시안이다.

화면의 동작과 서비스 함수 연결은 스크립트가 만드는 `../화면설계서.md`(와이어프레임)가 정한다. 이 문서는 시각 시안만 설명한다.

## 2. 제품 흐름

조사 등록 → 작업정보·참여자 등록 → 작업조건 입력 → 사진 등록 및 동의 → 자세 분석 결과 확인 → 조사자 검토·확정 → Excel 보고서 출력

대시보드는 진행 중인 조사와 최근 결과로 이 흐름의 진입점을 제공한다. 조사 생성과 작업 단계는 화면 상단의 진행 표시를 통해 현재 단계를 보여준다.

## 3. 공통 레이아웃과 디자인 규칙

### 3.1 레이아웃

- 상단 글로벌 헤더는 화면 높이 78px이며, 제품명, 주 메뉴, 조직 정보, 사용자 프로필을 담는다.
- 화면 제목과 설명은 좌측 40px 여백에 정렬한다.
- 본문은 화면 상단에서 205px부터 시작하고, 바깥쪽 좌우 여백은 기본 40px이다.
- 정보 영역은 흰색 카드로 구분하고, 카드 안쪽 기본 여백은 24px이다.
- 하단 작업 버튼은 공통으로 높이 44px, 모서리 반경 5px, 세로 위치 y=918px를 사용한다. 화면별 완료·비활성 상태는 색으로 구분한다.
- 화면 하단 고지와 제품 표기는 y=978px 구분선 아래에 배치한다.

### 3.2 색상과 형태

| 용도 | 값 |
|---|---|
| 기본 어두운색·주요 글자 | `#172230`, `#1B2635` |
| 주요 실행 버튼·강조 | `#FF6B43` |
| 화면 배경 | `#EEF1F5` |
| 보조 글자 | `#67788D` |
| 카드·입력 배경 | `#FFFFFF` |
| 기본 경계선 | `#DDE3EA` |
| 안내 박스 배경·경계 | `#FFF6E1`, `#EAD8AD` |
| 안내 강조선 | `#D9A23A` |

- 카드 모서리는 8px, 입력 필드는 4px, 버튼은 5px 반경을 사용한다.
- 주요 행동은 주황색, 보조 행동은 어두운 남색, 비활성 행동은 회색으로 표현한다.
- 안내 메시지는 옅은 노랑 바탕과 왼쪽 강조선으로 표시한다.

### 3.3 글자

- 글꼴은 `Malgun Gothic, Noto Sans KR, sans-serif` 순서로 지정한다.
- 화면 제목 30px, 카드 제목 18px, 본문과 입력 레이블은 주로 13–14px, 도움말·상태 표시는 11–12px를 사용한다.
- 강조 수준은 글자 크기와 굵기로 표현하며, 같은 위계에는 같은 크기와 굵기를 적용한다.

## 4. 화면별 설계

### 01. 대시보드

**목적:** 조사 업무의 진행 상황과 다음 작업을 한눈에 파악한다.

**주요 구성:**
- 조사 수와 상태별 요약 카드
- 최근 조사 목록과 조사별 상태·진행 정보
- 입력 또는 확인이 필요한 항목 요약
- 진행 중인 조사와 정기조사 일정 정보
- 조사 목록 또는 다음 단계로 이동하는 주요 행동

**상태:** 작성 중, 입력 필요, 확인 필요 등의 상태를 색상과 문구로 구분한다. 조사 결과에 대한 최종 책임이 사업주와 조사자에게 있음을 화면 하단에 고지한다.

### 02. 조사 목록과 조사 생성

**목적:** 저장된 조사를 검색·재개하고 새 조사를 등록한다.

**주요 구성:**
- 왼쪽 카드: 조사명·부서·공정 검색, 상태 필터, 조사일 정렬, 저장된 조사 표, 선택 조사 정보와 정기조사 안내
- 오른쪽 카드: 조사 구분, 조사일, 조사자, 부서, 작업공정명, 작업명 및 해당 시 수시 사유 입력
- 왼쪽의 ‘조사 다시 열기’와 오른쪽의 ‘필수 항목 확인 후 조사 만들기’ 행동

**간격 기준:** 두 카드의 바닥은 y=903px이다. 두 버튼은 y=841px에서 시작하고 높이는 42px이므로 카드 바닥과 버튼 사이에 각각 20px 여백을 둔다. 버튼 문구는 버튼 안에서 중앙 정렬한다.

### 03. 작업정보와 작업자

**목적:** 선택한 조사에 단위작업과 참여자 정보를 등록한다.

**주요 구성:**
- 조사 요약과 단계 표시
- 등록된 단위작업 목록과 단위작업 추가 동작
- 작업명, 작업 인원, 작업 기간 및 하루 작업시간 입력
- 참여자 목록, 참여자 추가, 표시 이름 사용 안내
- 이전 단계와 작업조건 입력으로 이동하는 하단 버튼

**상태:** 저장 여부를 표시하고, 미등록 참여자 등 확인이 필요한 정보를 구분한다.

### 04. 작업조건 입력

**목적:** 작업에 해당하는 부담작업 기준과 작업 내용을 입력한다.

**주요 구성:**
- 조사 요약과 단계 표시
- 기준별 체크 영역과 선택된 기준 요약
- 작업 내용, 작업시간, 횟수 등 입력 영역
- 선택·입력 방법을 설명하는 보조 안내
- 체크된 기준만 작업에 반영된다는 노란 안내 메시지
- 이전 단계 및 저장 후 사진 분석으로 이동하는 동작

**입력 원칙:** 작업 내용은 제공된 선택 항목을 우선 사용하되 직접 입력할 수 있다. 작업시간과 횟수는 직접 입력한다. 11개 기준의 세부 필드는 구현 전에 기능정의와 대조한다.

### 05. 사진 등록

**목적:** 단위작업의 분석에 쓸 사진 여러 장(표본)을 올리고 촬영·분석 동의를 확인한다.

**주요 구성:**
- 단위작업 연결과 사진 추가 (JPG·PNG, 여러 장 선택)
- 올린 사진 목록: 번호, 파일 이름, 빼기 (×는 표본에서만 빼고 사진 파일은 지우지 않는다)
- 촬영·등록 안내와 분석 전 확인 정보 (올린 사진 수, 최소 장수)
- 올린 사진 모두에 대한 촬영·분석 동의 확인
- 동의 상태에 따라 활성화되는 분석 시작 동작
- 사진이 최소 장수(5장)보다 적을 때의 노란 안내

**안내 박스 크기:** 하단 노란 안내 박스의 높이는 28px이다. 문구는 상하 공간에 맞춰 배치한다.

**상태:** 동의 전에는 분석 동작을 비활성화한다. 판별 가능한 사진이 5장보다 적으면 분석은 하되 자세 비율로 정하는 3·4·5호는 '사람 확인'으로 남는다.

### 06. 자세 분석 결과

**목적:** 대표 사진과 사진 표본의 분석 지표를 보여주고 조사자의 판단 검토를 요청한다.

**주요 구성:**
- 대표 사진과 관절 위치 표시
- 사진 줄: 사진별 판별 결과 (주황 = 허리 20° 이상 굽힘, 회색 = 판별 불가, 테두리 = 대표 사진)와 자세 비율 (해당 사진 수 / 판별 가능한 사진 수)
- 관절 각도·좌우 분석 요약 (대표 사진 기준)
- REBA 점수와 부위별 점수 표
- 점수 변화 가능성과 조사자 검토를 알리는 노란 안내 박스
- 부담작업 기준 초안과 노출시간 검토 상태 (자세 비율 × 하루 작업시간)
- 이전 단계 및 조사자 검토로 이동하는 동작

**간격 기준:** 점수 표 아래 구분선은 y=675px, 안내 박스 상단은 y=693px로 18px 간격을 둔다. 안내 박스 높이는 58px이다. 안내 박스 아래 ‘부담작업 기준 해당 초안’ 제목과 검토 항목은 간격을 두어 배치한다.

**안내 문구:** 각도를 ±5° 흔들었을 때 판정이 바뀔 수 있으며, 자동 확정하지 않고 조사자 검토를 요청한다.

### 07. 조사자 확인

**목적:** 초안 결과와 입력 필요 항목을 조사자가 확인·수정하고 확정 이력을 남긴다.

**주요 구성:**
- 조사 및 분석 요약
- 부담작업 기준별 판정 초안과 근거
- 확인·수정이 필요한 항목과 조사자 입력 영역
- 미확정 항목이 남아 있을 때 확정 버튼을 비활성화하는 안내
- 변경 이력 및 이전 단계 이동

**상태:** 초안, 입력 필요, 확인 완료, 확정 상태를 구분하고 변경사항 저장 상태를 표시한다.

### 08. Excel 문서 출력

**목적:** 조사 결과와 설정을 확인하고 Excel 보고서를 내보낸다.

**주요 구성:**
- 보고서 내용 미리보기
- 저장 위치와 파일명 입력
- 내보내기 시 데이터베이스 백업 포함 여부
- 미확정 판정이 보고서에 초안 상태로 표시됨을 알리는 안내
- 이전 단계 이동과 Excel 내보내기 동작

## 5. 상태 및 사용성 원칙

- 필수 입력 항목에는 별표를 표시하고, 누락 상태와 다음에 필요한 행동을 함께 안내한다.
- 저장 완료·작성 중·입력 필요·비활성 등 상태는 문구와 색상을 함께 사용한다.
- 분석 결과를 자동으로 최종 확정하지 않는다. 조사자가 결과를 확인하고 수정할 수 있어야 한다.
- 주요 버튼 문구는 수행 결과가 드러나는 동사형으로 작성한다.
- 안내 메시지는 관련 입력 또는 결과 영역 가까이에 배치하되, 표·버튼·제목과 맞닿지 않도록 여백을 둔다.

## 6. 범위와 전제

- 분석 입력은 단위작업마다 올린 사진 여러 장(표본)이다. 판별 가능한 사진이 5장보다 적으면 자세 비율로 정하는 호는 '사람 확인'으로 남는다 (기능정의서 v0.4, TP-12). 영상은 MVP 이후에 사진을 뽑아 쓰는 방식으로 더한다.
- 시안 화면에는 식별 가능한 실제 인물 이미지를 사용하지 않는다.
- 부담작업 기준의 세부 판정 및 최종 조사 결과 책임은 사업주와 조사자에게 있다.
- 예시 화면에 기재된 조사·조직·인물 정보와 날짜는 시안용 예시 데이터이다.
