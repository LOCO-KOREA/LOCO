S01 · 조사 목록 안내

사진 등록 촬영 안내

같은 조건의 정상 작업 3회에서 아래 다섯 순간을 촬영합니다. 일정한 시간 간격에 맞추지 않습니다.

  1. 손 닿기 전: 상자는 바닥, 손이 닿기 직전
  2. 바닥 분리 직후: 상자바닥 전체가 처음 떨어지고 중량은 손이 받음
  3. 바닥면 절반 높이: 상자 바닥이 선반높이/2를 통과
  4. 선반 접촉 직전: 틈이 있고 아직 중량은 손이 받음
  5. 손 놓은 후: 선반에 완전히 놓고 양손을 놓음

현재 사진 관찰값 입력

선택한 사진에서 몸통·목·위팔·아래팔·손목·다리 자세를 직접 확인합니다. 사진에서 판단할 수 없는 값은 비워 두고, REBA 점수 입력이 필요한 항목에 표시합니다.

4호 합산 해석

목·몸통·어깨·팔꿈치·손목·손의 부담 조건을 함께 살펴봅니다. 앱의 초안과 조사자 결론은 각각 남기며, 빠진 근거는 별도로 표시합니다.
