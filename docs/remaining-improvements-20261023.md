## 3. 남은 개선 2: REBA 1차 점수와 AI 설명의 분석 기준 불일치

### 증상과 확정한 원인

사용자는 화면에서 REBA 점수를 봤는데 AI 설명은 ‘사진 대상 1개 중 유효 0개, REBA 완료 0건’이라고 안내했다.

사용자 최신 저장 분석을 읽기 전용으로 확인한 결과, 최종 분석 자체가 대상 1개/유효 0개/REBA 완료 0개/최종 점수 null이었다. AI에 보낸 숫자는 이 최종 저장값과 일치한다. **저장된 최종 점수를 AI가 누락했다는 증거는 없다.**

화면의 1차 점수와 최종 분석이 서로 다른 경로다.

- `backend/engine/quick_assess.py`의 `provisional()`은 미확인 항목을 `NO_BURDEN`으로 가정하고 촬영 상황도 확인된 것으로 가정해 1차 점수를 만든다.
- 간편 화면 `finish()`는 저장된 작업으로 최종 분석을 시작하며 `preview.score`를 전달하지 않는다. 1차 점수는 최종 snapshot에 별도 보존되지 않아 이번 DB 조회로 사용자가 본 정확한 1차 수치까지 대조할 수는 없었다.
- `backend/gpt/payload.py`는 최종 `pose.valid_count`, `reba.complete_count/available_max/full_max`만 AI에 보낸다. AI는 앞서 보여 준 1차 점수와 가정 내용을 알 수 없다.
- 사용자 대표 사진은 측면 촬영 여부/한 사람/전신/평소 작업 확인값이 미확인이었고, 최종 REBA 입력 29항목이 비어 있었다. 사진에 관절이 검출돼도 촬영 상황 미확인으로 최종 유효 판정에서 제외될 수 있다. ‘유효 0’은 곧 ‘사진에서 사람이나 자세를 못 찾음’이 아니다.
- 화면에는 ‘1차 REBA 점수’와 가정 안내가 있지만, 큰 점수를 본 사용자에게 최종 AI 설명과의 연결이 충분하지 않았다. 최종 점수 화면 자체가 1차 점수를 대신 표시하는 구조는 아니다.

### 다음에 할 작업과 완료 기준

1. 1차 가정 점수와 확정된 최종 점수를 공통 계약으로 구분해 저장·화면·AI·Excel에 연결한다. 가정값을 최종 입력으로 복사하거나 완료 점수로 승격하지 않는다.
2. AI 요약에 1차 점수의 존재/가정, 실제 관측이 있음, 최종 미완성 이유를 필요한 숫자·구조 정보로 전달한다. 원문·사진 전체를 무조건 넘기는 식으로 허용 경계를 넓히지 않는다.
3. 촬영 상황 미확인, 관절 가림/저신뢰, 미선택 사진, 계산 입력 누락, 실제 분석 실패를 구분한다. 상황 확인만 필요한데 재촬영을 단정하지 않게 한다.
4. 이미 저장된 MediaPipe·Luna 관찰과 사용자/AI 입력을 최대한 재사용하고 모르는 사실은 추측해 채우지 않는다.
5. 기존 분석 snapshot과 과거 AI 문장을 덮어쓰지 않는다. 새 설명/분석의 버전과 근거로 구분한다.
6. 완료 기준: 화면에서 본 점수의 단계·근거를 최종 AI/Excel에서 추적할 수 있어야 하며, 동일 사진이 ‘관측 있음’과 ‘관측 없음’으로 모순되게 설명되지 않아야 한다. 최종 미완성인 경우 필요한 이유만 정확히 설명해야 한다.

## 4. 남은 개선 3: Excel의 과도한 입력 요구

### 현재 상태

사용자가 Excel에서도 입력을 너무 많이 요구한다고 보고했다. 사용자 사례에서 최종 REBA 입력 29항목 누락은 확인했지만, Excel 파일 생성 자체가 무엇을 강제하는지와 안내 목록을 강제 입력으로 받아들이게 하는지는 아직 별도 실화면 재현을 하지 않았다. 실제 강제 여부가 확인된 것처럼 단정하지 않는다.

main의 Excel 부위별 보완 안내·표시 구성은 이번 병합에서 유지한다. 표기만 정리한 것으로 입력 요구 최소화까지 완료한 것은 아니다.

### 다음에 할 작업과 완료 기준

1. Excel 생성 필수 정보, 최종 REBA 완성에 필요한 정보, 선택 검토 항목을 실제 경로에서 전수 대조한다.
2. 이미 사용자/AI 설명·MediaPipe·Luna에 있는 같은 사실을 다시 요구하는 경로를 확인하고 저장·조건 연결을 고친다. 중량·시간 등 알려진 값이 사라지거나 다른 조건에 연결되지 않게 한다.
3. 현재 정보로 출력할 수 있는 경우 선택 보완 때문에 출력을 막지 않는다. 미확정 항목은 빈값/확인 필요로 보존하며 NO/0을 임의로 채우지 않는다.
4. 필요한 미확인 사실만 묶어서 최소 횟수로 묻는다. 저장 필드 수와 실제 답변 횟수를 구분해 기록한다.
5. main의 화면 디자인·구성·사진 크롭·Excel 형식을 유지한다. 사용자 마우스·키보드를 사용하지 않는 격리 실스택 검증으로 확인한다.
6. 완료 기준: 기존 입력 재질문 0건, 불필요한 필수 입력 0건, 실제 질문 수 기록, 사용자 원문/AI 채택값→DB→선택 분석→실제 Excel 셀 대조가 통과해야 한다.
