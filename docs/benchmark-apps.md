## 1. POCO (AI 자세분석)

### 이 앱은 누구를 위한 앱인가?

- **주요 사용자**: 체육관, 요가·필라테스, 피트니스 등 체육시설의 지도자와 회원 [자료]
- **사용자가 해결하려는 문제는?** 회원의 체형 불균형(거북목, 골반 경사 등)을 상담 때 빠르게 확인하고 교정운동을 추천하는 것 [자료]

### 입력 방식은?

- [x] 사진: 스마트폰·태블릿으로 정면과 측면 촬영 [공식]
- [ ] 영상
- [ ] 실시간 카메라
- [ ] 기타

### Pose Estimation은 어디에 사용되는가?

정지 사진에서 머리, 어깨, 골반, 발목 등 주요 관절 점을 찾아 각도와 좌우 차이를 계산한다. [자료]

### 분석하는 내용은?

- [x] Keypoint
- [x] 관절각
- [x] 좌우 균형
- [x] 자세 분류: 거북목, 골반 전방·후방 경사, O다리·X다리 등 [공식]
- [ ] 반복 횟수
- [ ] 동작 단계
- [ ] 기타

### 사용자에게 어떤 결과를 보여주는가?

30초 이내에 체형과 신체 불균형 분석 결과, 맞춤 교정운동 추천 [자료: 전자신문 2023-11-29]

### 주요 화면은?

- 시작 화면: 확인 못 함 (회원가입은 전화 문의 후 계정 발급) [공식: 앱스토어 리뷰 답변]
- 촬영/분석 화면: 정면·측면 촬영
- 결과 화면: 체형 불균형 항목별 결과
- 기록/리포트 화면: 분석 결과 리포트 [공식]

### 우리가 참고하고 싶은 기능 3개

1. 정면·측면처럼 촬영 방향을 정해 주는 촬영 안내
2. 항목별로 정리된 결과 리포트
3. 결과에서 바로 다음 행동(교정운동)으로 이어 주는 구성

### 불편하거나 개선하고 싶은 점

1. 정지 사진만 보므로 작업이나 운동 같은 **동작**은 평가하지 못한다. [판단]
2. 결과가 얼마나 믿을 만한지(확신도) 보여주지 않는다. [판단]
3. 결과가 공식 평가도구나 법정 서식과 연결되지 않는다. [판단]

> 참고: 개발사는 부산인터넷방송국(스마트어플)이며, 우리가 받은 샘플 코드(구글 TensorFlow 포즈 예제)를 사용했다고 전달받았다. 샘플은 POCO의 소스 코드가 아니다.

## 2. 엑스바디 (exbody)

### 이 앱은 누구를 위한 앱인가?

- **주요 사용자**: 병의원, 한의원, 피트니스, 필라테스, 보건소, 기업, 학교, 연구기관 [공식]
- **사용자가 해결하려는 문제는?** 검사를 통해 근골격 질환을 예방하고 관리하는 것. 기업 대상으로 "임직원 근골격 예방관리" 방문형 서비스가 있다. [공식]

### 입력 방식은?

- [ ] 사진
- [ ] 영상
- [ ] 실시간 카메라
- [x] 기타: 전용 장비 도입형으로 보인다("장비 및 도입 문의"). 촬영 방식의 상세는 확인 못 함

### Pose Estimation은 어디에 사용되는가?

관절의 굴곡·회전 각도를 측정한다. 공인 기관 검사 정확도로 목 굴곡 96%, 어깨 외회전 96%, 팔꿈치 굴곡 98%, 무릎 굴곡 97%, 고관절 굴곡 96%·내회전 97%를 제시한다. [공식]

### 분석하는 내용은?

- [x] Keypoint
- [x] 관절각 (굴곡·회전)
- [ ] 좌우 균형: 확인 못 함
- [ ] 자세 분류: 확인 못 함
- [ ] 반복 횟수
- [ ] 동작 단계
- [ ] 기타

### 사용자에게 어떤 결과를 보여주는가?

관절별 측정 결과로 질환 예방·관리를 돕는다고 설명한다. 결과 화면의 구체적인 구성은 확인 못 함. [공식]

### 주요 화면은?

확인 못 함 (홈페이지에 화면 공개 없음)

### 우리가 참고하고 싶은 기능 3개

1. 관절별 측정 정확도를 공인 기관 기준으로 숫자로 제시하는 방식
2. 업종별(보건소, 기업, 학교) 맞춤 제안
3. 기업 임직원 근골격 예방관리처럼 B2B로 들어가는 방식

### 불편하거나 개선하고 싶은 점

1. 사람의 몸(관절 가동범위)을 보는 검사라서, **작업 자체**의 위험(어떤 작업 자세가 하루 얼마나 반복되는지)은 다루지 않는 것으로 보인다. [판단]
2. 전용 장비가 필요해 작업 현장에서 바로 쓰기 어렵다. [판단]
3. 유해요인조사표 같은 법정 서식과의 연결은 공개 자료에서 확인되지 않는다. [판단]

## 3. 모라핏 (MORA Fit)

### 이 앱은 누구를 위한 앱인가?

- **주요 사용자**: 필라테스·피트니스 강사와 회원 [공식]
- **사용자가 해결하려는 문제는?** 회원이 강사의 운동 처방을 신뢰하지 않거나 운동 전후 변화를 이해하지 못하는 문제 [공식]

### 입력 방식은?

- [ ] 사진
- [ ] 영상
- [x] 실시간 카메라: 태블릿 하나로 1분 안에 측정 [공식] (사진·영상 구분은 확인 못 함)
- [ ] 기타

### Pose Estimation은 어디에 사용되는가?

자체 AI 모델(GRIFFIN 1.4.0)로 관절 포인트 24개를 분석해 자세 정렬과 운동 기능을 평가한다. 공인 기관(KTL) 기준 각도 대비 오차 ±2.5° 이내라고 밝힌다. [공식]

### 분석하는 내용은?

- [x] Keypoint (24개)
- [x] 관절각
- [x] 좌우 균형 (자세정렬평가)
- [ ] 자세 분류
- [ ] 반복 횟수: 확인 못 함
- [ ] 동작 단계: 확인 못 함
- [x] 기타: 운동기능평가(종합 신체능력) [공식]

### 사용자에게 어떤 결과를 보여주는가?

자세정렬평가와 운동기능평가 결과. 운동 전후 변화를 보여 주어 회원을 설득하는 데 쓴다. [공식]

### 주요 화면은?

- 시작 화면 / 촬영·분석 / 결과 / 기록: 홈페이지에 측정 단계 그림이 있으나 화면 상세는 확인 못 함

### 우리가 참고하고 싶은 기능 3개

1. 각도 오차를 공인 기관 기준(±2.5°)으로 밝히는 정확도 표현 방식
2. 고정 장비 없이 태블릿 하나로 측정하는 낮은 도입 장벽
3. 개인정보 국제 인증(ISO/IEC 27001·27701)을 앞세운 신뢰 확보

### 불편하거나 개선하고 싶은 점

1. 운동 지도용이라 작업 현장의 유해요인 평가나 법정 서식과는 연결되지 않는다. [판단]
2. 측정이 불확실할 때 사람에게 넘기는 장치가 보이지 않는다. [판단]
3. 구독형이라 한 번 하는 법정 조사 용도에는 맞지 않을 수 있다. [판단]

## 참고: 법정 조사 도구 ergo-C (멘토 목록 밖, 2026-10-09 추가)

> https://ergo-c.com/ · 인간공학기술사 추철웅(강남세브란스병원 안전보건파트장)이 운영하는 도구 모음 사이트. 회사라기보다 전문가 한 사람의 사이트이고 광고와 컨설팅 문의가 붙어 있다. [공식]
> 확인 방법: 가입 없이 열리는 체험 화면(`/hazard/demo.html`)과 공개 페이지 (2026-10-08). 가입해야 쓰는 실제 앱은 써 보지 않았다.

### 주요 기능

- [x] 근골격계 유해요인조사: 법정 서식(별지 제1호) 순서 그대로 7단계 (조사 개요 → 작업장 상황 → 작업조건 1·2·3단계 → AI 분석 → 완료) [공식]
- [x] AI 분석: 작업 사진(정면·측면)과 입력값을 Google Gemini에 보내 REBA 각도·점수 초안, 개선안, 종합의견을 만든다. 조사자가 확인·확정한다 [공식]
- [x] 결과물: 유해요인조사표(별지 제1호) Word 파일을 이메일로 보낸다 [공식]
- [x] 부담작업 11개 판단: 노출 시간·횟수를 사람이 입력하면 판단하고 결과서를 인쇄한다 (브라우저 안에서만 계산) [공식]
- [x] 증상조사: 근로자가 QR로 응답하면 통계 보고서가 자동으로 나온다 [공식]
- [x] 평가도구 8종 계산기 (REBA·RULA·OWAS·NLE·JSI·Snook·WAC·QEC) [공식]
- [ ] 영상 분석
- [ ] 측정 정확도 공개
- 가격: 가입하면 보고서 2건 무료, 그 뒤 토큰·단체플랜은 메일 문의 (공개 가격 없음) [공식]
- 실적: 병원 병동 16개 작업을 조사한 결과물 3종(조사표, 증상조사 보고서, 종합보고서) 공개 [공식]

### 좋은 점 (배울 것)

1. 법정 서식 순서를 그대로 화면 흐름으로 만들어 조사자에게 익숙하다.
2. "AI는 보조, 판단은 조사자"를 화면마다 밝힌다. 우리 원칙과 같다.
3. 실제 조사 결과물을 공개해 결과물 모양을 먼저 보여 준다.

### 한계 (우리가 풀려는 것)

1. 사진 한 장은 한 순간이다. ergo-C도 어느 순간을 찍었느냐에 따라 REBA가 달라진다며 일부 작업은 다시 찍으라고 권했다. [공식]
2. 하루 노출 시간을 사람이 분 단위로 입력한다. 공개 사례에서도 4개 작업의 노출 시간·횟수가 빈칸이었다. [공식]
3. 각도를 재지 않고 생성형 AI가 사진을 보고 추정한다. 정확도 수치는 공개되어 있지 않다. [판단]
4. 작업 사진과 입력 정보(근로자 이름 포함)가 외부 AI(Google Gemini)로 간다. [공식]

## 정리: 유사 서비스와 우리 서비스의 차이

| 항목 | POCO | 엑스바디 | 모라핏 | ergo-C | **우리 서비스** |
|---|---|---|---|---|---|
| 대상 | 체육시설 회원 | 의료·보건·기업 | 필라테스·피트니스 | 사업장 안전보건관리자 | **사업장 유해요인조사자** |
| 입력 | 정면·측면 사진 | 전용 장비 | 태블릿 카메라 | 작업 사진 + 노출 시간 직접 입력 | **작업 사진 여러 장(표본) + 하루 작업시간 입력** |
| 보는 것 | 정지 체형 | 관절 가동범위 | 정렬·운동 기능 | 한 순간의 작업 자세 | **작업 자세와 하루 노출 (사진 표본의 비율)** |
| 결과 | 체형 리포트 | 관절 측정 결과 | 정렬·기능 평가 | REBA 초안, 법정 서식 Word | **REBA 점수, 부담작업 11개 기준 판정 초안과 경고, 엑셀 보고서** |
| 불확실할 때 | 표시 없음 | 확인 못 함 | 표시 없음 | 조사자가 확인·확정 | **사람 확인으로 넘김** |
| 사진 처리 | 확인 못 함 | 확인 못 함 | 확인 못 함 | 외부 AI(Gemini)로 전송, 각도는 AI 추정 | **PC 안에서 처리 (MoveNet Lightning), 각도 출력, 얼굴 모자이크** |

**우리가 비어 있다고 본 자리**: 작업 사진 여러 장의 관절을 재서 자세가 차지하는 시간 비율을 구하고, 하루 노출 시간을 법 기준(부담작업 11개 기준, 각도는 고용노동부 해설)과 바로 잇고, 사진을 PC 밖으로 보내지 않는 도구. 모르는 칸은 사람에게 넘긴다. 사진 한 장으로 추정해 법정 서식을 만드는 도구(ergo-C)는 이미 있으므로, 우리의 차이는 '한 순간이 아니라 사진 표본의 비율', '각도를 재서 근거로 남김', 'PC 안에서 처리'다. 영상 분석은 MVP 이후다. [판단]

> 참고 (멘토 목록 밖): 해외의 Intenseye는 CCTV로 REBA·RULA를 상시 분석하고, TuMeke는 영상으로 REBA·RULA·NIOSH를 자동 계산하는 상용 제품이다. 국내에서는 대한산업보건협회가 2024년에 영상 AI 판독 시스템을 시연했으나(산업일보 2024-07-04) 상용 제품은 확인하지 못했다. [자료]
