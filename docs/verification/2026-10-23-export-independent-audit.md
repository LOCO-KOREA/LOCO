# 저장 결과 및 Excel 독립 감사

이 문서는 `d98ad3f5afec904c1edb875e1266467241a8a5ce`에서 실행한 첫 외부 Luna 캠페인과, 해당 캠페인 07의 저장 결과를 독립 DB로 복제한 재현을 기록한다. 최종 후보의 새 외부 호출 결과와 구분한다. 사용자의 마우스·키보드는 사용하지 않았다. 모든 Electron 창은 `LOCO_HIDDEN=1`, 화면 밖 위치, `focusable=false`, 독립 DB/프로필이다.

## 첫 외부 호출 12개 사례의 독립 대조

원본 캠페인 파일은 변경하지 않고 JSON/JSONL 사본에 수정된 감사 도구를 실행했다. Excel 파일은 원본 파일을 읽기만 했다.

- UI의 최종 재시작 단계 완료: 10/12.
- 초기 기대값·DB·계약·스냅샷·Excel 대조 전부 통과: 8/12.
- 첫 AI 응답의 선언된 기대값: 63개 중 60개 일치.
- 독립 대조 항목: 25,668개.
- SDK에 기록된 실제 외부 요청/응답: 62/62. 단위 조합 450+144를 외부 AI 호출로 세지 않는다.
- 실패: 07·10은 고급 Excel 화면 이동 경합으로 중단, 08은 처음 입력한 `UNLOADED` 누락, 11은 손목·손 각각 180분 누락.

06의 입력 끝 공백은 서비스의 `strip()` 경계 정규화였다. IPC 원문과 내부 문장·수치는 보존돼 있었다. 감사가 원문 끝 공백까지 같은 문자열을 찾던 오판을 수정했다. 비교에는 앞뒤 공백 제거만 허용하며, 문장 안 공백·줄바꿈·숫자 변화는 계속 실패한다. `oracle-review.json` 파일로 08 기대값을 삭제하는 과거 예외도 제거했다.

초기 기대값 수는 사례 순서대로 8, 4, 4, 4, 3, 4, 4, 5, 3, 8, 10, 6개다. 08은 4/5, 11은 8/10이며 나머지는 전부 일치했다. 후속 입력으로 보완됐더라도 초기 누락은 그대로 실패로 남긴다.

증거 위치는 감사 worktree의 `.local/independent-first-campaign/independent-summary.json` 및 각 사례 `audit.json`이다. 외부 호출 원본은 통합 worktree의 `.local/live-field-cases-20261023`과 `.local/live-posture-cases-20261023`에 있다.

## 07의 실제 앱 재현 및 수정

07의 닫힌 원본 SQLite를 `mode=ro` 연결과 SQLite backup API로 독립 DB에 복제했다. 기존 analysis 2, 이미 적용한 설명, 사진 크롭 파일을 사용했다. 새 자연어 제출·외부 AI·분석 실행은 없었다.

원인은 제품의 화면 이동 경합이었다. 간편 화면의 상세 열기는 곧바로 고급 탐색 버튼을 표시하지만 작업 조회는 비동기로 진행한다. 성공한 `get_task` 응답 하나를 테스트에서 보류하고 S08을 열면, 응답 해제 뒤 늦은 `TaskWorkspace.render()`가 S04로 되돌렸다. 실제 Python 응답 값과 SQLite는 변경하지 않은 지연 순서 재현이다.

수정은 탐색 소유권 토큰을 사용한다. 늦은 조회는 취소하지 않고 값을 호출자에게 반환한다. 사용자가 이미 다른 화면·작업을 선택했으면 이전 요청이 현재 작업과 화면을 덮지 않는다. 단위 회귀는 응답을 보류한 상태에서 소유권을 바꾸고, 새 작업 유지와 늦은 응답 정상 반환을 모두 확인한다.

캠페인 harness도 상세 S04 및 작업 문맥의 실제 표시를 기다린 뒤 S08을 선택하도록 보강했다. 간편 Excel이 기본 경로이고 `LOCO_EXPORT_MODE=advanced`로 고급 경로를 선택할 수 있다.

수정 후 실제 숨김 앱 재현은 다음을 대조한다.

- 간편/고급 두 Excel 실제 저장 및 preview의 정확한 셀/단위 일치.
- 원본 DB의 모든 행 불변, 기존 분석과 적용 설명 불변.
- 저장된 analysis 2의 입력과 두 출력 스냅샷 동일.
- 사용자 입력·AI 정리 값·출처·크롭 사진 정보 보존.
- 같은 worktree에서 다시 열 때 TASK의 전체 바이트 및 revision 불변.
- 새 외부 AI 요청 및 새 분석 실행 0.

대표 사진 번호가 없는 미완성 REBA 결과에서는 Excel 대표 이미지도 없다. 사진 크롭의 등록·원본 보존과 대표 이미지의 유무를 구분하며, 이미지가 존재한다고 임의 판정하지 않는다.

다른 worktree로 DB를 복제하면 절대 모델 경로가 fingerprint에 포함돼 동일 파일의 POSE 관찰을 한 번 다시 측정할 수 있다. 이때 자동 관찰의 시각·fingerprint·projection revision만 달라지고 사용자 값과 과거 분석은 그대로인지 별도로 대조한다. 같은 경로의 반복 조회 불변 검사와 이 이동 경계를 혼동하지 않는다. 이번에는 이 캐시 계약을 변경하지 않았다.

재현 명령:

```powershell
node tests/replay_stored_export.cjs <원본-사례-폴더> <새-독립-출력-폴더>
.\.venv\Scripts\python.exe -X utf8 tests/audit_recorded_campaign.py <새-감사-폴더> <완료된-캠페인-폴더> [추가-캠페인-폴더]
```
