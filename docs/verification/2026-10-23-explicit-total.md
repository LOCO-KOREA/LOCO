# 명시 총시간과 불필요 calculation 검증

실제 Luna EXTRACT/FOLLOWUP이 모두 daily_work_min=300, 인용 “하루 전체 실제 작업시간은 5시간입니다.”와 인용 밖 두 작업의 120/180분 합산을 함께 반환한 원응답을 보존했다. 변경 전에는 둘 다 UNIT_OR_NUMBER_NOT_GROUNDED였다. 새 우선순위는 단일 확정 총시간을 독립 검증해 저장하고 원제안의 calculation은 이력에만 그대로 보존한다.

`tests/test_intake_explicit_total.py` 5개 시험과 기존 시간/원문 교차검토 회귀까지 25개 통과. 실제 서비스+격리 SQLite에서 원응답 두 개 재생→300분 저장→원문 message 연결→재시작→분석 snapshot→Excel의 300 분/일 및 실제 인용 셀을 대조했다. 이후 USER 420 수정 우선권과 과거 snapshot 불변도 확인했다. 이 재생은 새 외부 호출이 아니다.

음성 회귀: 틀린 총값, 분/초/kg 단위 불일치, 틀린 괄호 환산, 원문 없는 인용, 잘린 복합 시간, 범위·부정·근사·모름 총시간, 명시 총시간 없이 없는 피연산자·잘못된 환산·한 위치 중복 합산을 계속 거절한다. 직접 검증한 총시간이 있는 경우, 불필요하고 미검증된 계산 메타데이터는 저장 근거로 사용하지 않는다.
