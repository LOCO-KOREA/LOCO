# 최신 main 통합·재질문 점검

기준 origin/main 020d8547b7afccc84de09c633c16423a8e342531. 브랜치 integrate/mediapipe-latest-main-20261023. 이전 작업 복사본은 보존하고 최신 main에 우리 작업 패치만 3-way 적용했다. main의 사진 크롭 모듈/서비스와 Excel 출력 경로는 유지한다. 실제 검증 결과는 실행 완료 후 아래에 기록한다.

## 이미 입력한 값의 재질문 점검

계약 필드 90개 × 상태/출처 5가지 = 450개 조합. 다른 항목이 비어 있는 작업에서 각 필드 하나를 채우고, 후보·개별 질문·묶음 질문·좌우 짝 질문에 같은 identity가 들어가지 않는지 검사한다. 직접 입력 KNOWN, AI KNOWN, 사진 KNOWN, 기존 저장 KNOWN, USER UNKNOWN을 검사한다. 이는 질문 제외 정책 검사이며 사진 추론기가 중량/시간을 알 수 있다는 뜻이 아니다.

별도로 실제 0·NO·조건별 서로 다른 중량·횟수·확인된 20kg 연결·재열기와 revision 불변·다중 중량·명시적인 모름을 검사한다. 이미 정리한 필드는 간편 기본 입력에서 제외하고 수정 영역에 보존한다. 기존 회귀 시험의 좌우 독립성·추정/충돌 확인·사진 교체·지연 응답·직접 입력 우선권도 유지한다.

다른 조건/사진이거나 추정·충돌 상태인 경우에는 추가 확인이 필요하다. 무게를 말했다는 이유로 사진 속 물건도 같은 무게라고 추측하지 않으며, 같은 물건이라는 확인이 있으면 재사용한다. 서로 다른 작업의 시간을 하루 전체 시간이라고 추측하지 않는다. 명시한 총시간 또는 근거가 검증된 합산 값은 다시 묻지 않는다. 사용자 모름은 질문 처리 완료이며 계산 완성을 의미하지 않는다.

실제 호출 및 Excel 셀 대조 실행 진행 중. 완료 결과를 기록하기 전에는 전체 E2E 통과로 간주하지 않는다.


## 공식 사례를 바탕으로 한 조합 시나리오

공식 자료는 작업 유형과 조사 항목의 출처로 사용했다. 아래 입력 문장·중량·시간·횟수·사진은 재현 가능한 합성 시험 자료이며 원 사업장의 측정값이나 판정이 아니다. 급식 가이드북 PDF 35쪽 중 7쪽의 조사표를 다운로드·렌더링하여 확인했다. 해당 표의 O/X를 앱의 다른 작업에 그대로 적용하지 않는다. 그 밖의 공식 카탈로그는 검색 본문으로 작업 유형을 확인했으며, 직접 접근에 제한이 있던 자료는 출처 JSON에 명시한다.
