## 구현된 입력 보존과 질문 최소화

입력 원문, AI 제안 원문과 채택·거절 기록, 사진별 측정, 직접 답변·모름, 불변 분석/출력 snapshot을 유지한다. 20kg 재질문, 중복 저장 카드, 개발용 상태·출처 노출, 문장 일부 인용 누락, 명시 총시간의 불필요 합산 검증, 사진 소유권과 늦은 화면 복원 경합을 수정했다. 이미 알려진 값은 같은 조건·사진에서 다시 묻지 않고 빈 단계를 넘긴다. 남은 작업 부재는 한 번에 확인한다. 알 수 없는 값을 NO/0으로 채우지 않으며 응답의 나이만으로 버리지 않는다.

MediaPipe Heavy의 각도·품질·신체 좌우·원 사진을 보존하고 신뢰도와 경계 검사를 통과한 측정만 자동 반영한다. 다른 사진의 빈 입력을 대신 채우지 않는다. 모델/추론·정책·계약은 공통 모듈과 설정에서 공급한다.

## 새 Luna 사진 관찰

사용자의 새 지시에 따라 기존의 사진 판독 제외 범위를 변경했다. 이제 실제 등록한 크롭 사진을 gpt-6-luna/xhigh에 input_image로 전송하고 사진마다 동작·몸통·목·무릎·양팔·양손목·잡는 모습 9개 관찰을 받는다. 사용자 화면에는 한국어 관찰과 가림/불확실 이유를 표시한다. photo_vision 원문과 source/encoded SHA·응답·소유권은 기존 JSON 구조에 저장하고 이미지 base64는 DB에 저장하지 않는다.

분명히 관찰한 허용 boolean/작업 특징 후보만 자동 입력에 반영한다. 사용자 직접/명시 텍스트·저장값·유효한 MediaPipe 측정을 우선하며 사진으로 무게·시간·횟수·정확한 각도·법적 판정을 추측하지 않는다. 사진 상황을 사용자가 부정하면 VISION 소유 입력만 해제하고 원 관찰은 보존한다. 모델/프롬프트/사진 바이트·방향·등록 UUID에 묶인 캐시는 시간 만료 없이 재사용하고 사진 재등록·삭제 중 지연 응답이 새 사진에 적용되지 않게 한다.

기존 Excel 시트·셀을 유지하고 관찰이 있으면 ‘AI 사진 관찰’ 시트를 끝에 추가한다. 선택한 분석의 불변 snapshot에서 사진별 관찰 9개와 근거·불확실 이유를 출력한다. [계약과 설정](photo-vision.md) 참조.

## 검증 기록의 구분

기존 입력/보존의 실호출 12개는 c886b8d와 동일한 앱 내용에서 완료했다. 새 사진 기능과 혼합하지 않는다. [12개 독립 감사](verification/2026-10-23-final12-independent.md)와 [이전 수정 이력](verification/2026-10-23-main-no-repeat.md)을 참조한다. 최초 실패·디스크 부족 및 재시도 선택을 원래 증거와 함께 보존했다.

f909714에서는 실제 3개 크롭 사진→Luna 응답→UI/물리 DB/불변 분석/실제 Excel 27행 대조와 재시작이 통과했다. 최소 질문 A/B/C도 실호출→Excel까지 완료했고 추가 팝업은 0/1/1개였다. 이후 등록 UUID·사용자 상황 부정·명시 텍스트 우선권 후속은 별도 최종 소스와 검증 근거로 기록한다. 모든 자연어·사진 조합의 정확성 보증은 아니다.

최종 런타임 코드는 e8ded39로 고정했다. 전체 Python unittest 441개 통과(skip 0), 프론트엔드 24개 검증 스크립트와 build 통과. unit child 환경에서만 API 키를 제거해 비의도 실호출을 막았으며, 실제 UI 시험은 기존 승인된 키로 별도 실행했다. 로그는 `.local/vision-final-python.log`, `vision-final-frontend.log`, `vision-final-build.log`다.

최종 e8ded39 앱에서 사진 3장 실호출을 다시 완료했다. 실제 요청 5/응답 5/오류 0(사진 3+텍스트 2), UI 34개·물리 DB/Excel 27행 136개 대조·저장결과 전체 27개 항목 표시가 모두 통과했다. 재조회와 재시작에는 추가 API 호출이 없었다. 이전 f909714 응답의 선택 근거 수가 달라 그때의 142개를 최종 수치와 혼합하지 않는다. [최종 사진 독립 감사](verification/2026-10-23-vision-independent.md) 참조.

현재 보이는 새 창은 **LOCO · AI 사진 분석 수정본 (e8ded39)**, Electron PID 73860, CDP loopback 18875다. 실제 backend 연결·gpt-6-luna/xhigh·mediapipe-heavy·API 키 존재를 확인했고 키 값은 출력하지 않았다. 앱 폴더 `.local/manual-vision-e8ded39/`에 준비/연결 증거가 있다. 이후 docs/scripts 커밋은 앱 코드에 영향을 주지 않는다.
