# 프로젝트 개요

> 멘토님 「프로젝트 개요 템플릿」 형식 · 작성 2026-10-08 (팀 결정 반영판) · 수정 2026-10-12 (개발 동결 10/23, MVP는 사진 분석, 모델은 MoveNet Lightning) · 팀: 한정욱 · 김나리 · 유서하 · 정혁

## 1. 프로젝트명

근골격계 유해요인조사 보조 앱 (가칭) · PC(윈도우) 설치형 프로그램

## 2. 문제 정의

**사용자가 겪는 문제는 무엇인가?**

- 근골격계부담작업이 있는 사업장은 최초 조사 후 **3년마다** 유해요인조사를 해야 한다. 신설 사업장은 1년 이내, 질환자 발생·새 작업이나 설비 도입·작업환경 변경 때는 수시로 해야 한다. (산업안전보건기준에 관한 규칙 제12장, KOSHA GUIDE H-9-2022)
- 조사자는 작업을 직접 보거나 영상에서 자세를 골라 관절 위치를 정해 평가한다. 이 과정에 주관이 들어가 조사자마다 결과가 달라질 수 있고 시간이 많이 든다. (대한산업보건협회 자료)
- 동영상 촬영과 모바일 설문을 함께 쓰는 조사 사례는 있지만, 그 영상을 분석해 조사 결과로 이어 주는 도구는 찾지 못했다. 사진 한 장을 생성형 AI가 보고 REBA를 추정해 법정 서식을 만드는 도구(ergo-C)는 있다. 이 도구는 한 순간만 보고 노출 시간을 사람이 입력한다. 작업 사진 여러 장으로 자세의 시간 비율을 재서 법 기준과 잇는 도구는 찾지 못했다. (benchmark-apps.md)

## 3. 주요 사용자

- **Primary User**: 사업장의 유해요인조사자(보건관리자·안전관리자), 조사를 대행하는 외부 전문기관 담당자
- **Secondary User**: 사업주(조사 결과 확인), 해당 작업 근로자(촬영 대상, 면담 참여)

## 4. 서비스 한 문장

우리 서비스는 **유해요인조사자**가 **근골격계 유해요인조사를 빠르고 일관되게 하기 어려운 문제**를 해결할 수 있도록 **작업 중 찍은 사진 여러 장과 하루 작업시간**을 분석하여 **REBA 점수, 법 기준(부담작업 11개 기준) 판정 초안과 경고, 엑셀 보고서**를 제공하는 서비스이다.

## 5. 주요 입력

- [x] 사진: 찍어 둔 작업 사진 여러 장을 올린다 (한 사람만, 옆모습·전신, 작업 중 일정한 간격으로)
- [ ] 영상 (MVP 이후. 영상에서 사진을 뽑아 쓰는 방식으로 붙인다)
- [ ] 실시간 카메라
- [x] 기타: 단위작업별 하루 작업시간·하루 횟수·무게, 사진으로 재기 어려운 값(키보드 작업시간, 손목, 목·허리 비틀림, 지지 여부 등)

## 6. 주요 출력

- 관절이 그려진 분석 사진과 가장 위험한 사진 (얼굴은 자동 모자이크)
- REBA 점수(1~15)와 위험 단계 — KOSHA 지침 부록 2의 평가도구, 위험 정도 표시용
- 부담작업 11개 기준(고용노동부고시 제3조) 판정 **초안**과 근거 (자세 항목은 사진 표본의 비율 × 하루 작업시간이고 자세 각도는 고용노동부 해설 값, 반복·무게·횟수 항목은 입력값)
- 법 기준에 걸리면 경고 (경고 기준 = 법 기준)
- 칸마다 확신도: 자동 / 사람 확인 필요
- 엑셀 보고서: 요약, 작업별 결과(대표 사진 포함), 경고 기록, 판정 초안
- GPT가 쓴 쉬운 설명과 개선 조언 (점수·판정 계산에는 쓰지 않고, 숫자만 보냄)

## 7. 핵심 가치

**사용자가 이 서비스를 사용하면 무엇이 달라지는가?**

- 사진에서 자세를 고르고 각도를 재는 시간이 줄어든다.
- 같은 사진과 입력이면 같은 결과가 나와서 조사자마다 다른 결과가 줄어든다.
- 법 기준을 그대로 따른다. 자세 각도는 고용노동부 해설 값(허리 굽힘 20° 등)을 쓰고 출처를 보여 준다. 법과 해설에 없는 값은 앱이 만들지 않고 조사자가 정한다.
- AI가 확신하지 못하는 칸은 사람에게 넘기므로, 자동화하되 판정 책임은 사람이 지는 법의 구조를 지킨다.
- 결과가 엑셀로 바로 나와 문서 작업이 줄어든다.

## 8. 이번 프로젝트 범위

### 포함

- PC(윈도우) 설치형 프로그램 (Python)
- 작업 사진 올리기와 분석, 관절 추출 (모델은 MoveNet Lightning으로 확정, 2026-10-12)
- REBA 점수와 위험 단계
- 부담작업 11개 기준 판정 초안, 법 기준 경고, 확신도, 조사자 확정과 수정 이력
- 얼굴 자동 모자이크
- 엑셀 보고서, GPT 설명·조언 문장
- 팀원이 재연한 작업 6가지로 정확도 평가

### 제외

- 실시간 카메라나 CCTV 상시 분석 (찍어 둔 사진만 분석)
- 영상 올리기와 프레임별 분석 (MVP 이후)
- 모바일 앱 (안드로이드·아이폰)
- 실제 사업장 촬영과 현장 검증 (팀원이 작업을 재연해 촬영)
- 판정의 자동 확정 (확정은 항상 조사자)
- REBA 외 평가도구 (RULA, OWAS, NLE 등)
- 손목 각도와 목·허리 비틀기의 자동 측정 (조사자가 입력)
- 법과 고용노동부 해설이 정하지 않은 기준값을 앱이 정하는 것
- 의학적 진단, 근로자 개인 평가

### 시간이 남으면

- 법정 서식 자동 작성: 유해요인조사표(별지 제1호), 근골격계질환 증상조사표(별지 제2호)
- 근로자 안내문, 표본 수 계산 도우미, 이전 조사와 비교

### MVP 우선순위 (만드는 순서)

| 구분 | 기능 | 목표일 |
|---|---|---|
| Must | 사진 올리기 → 관절 → 각도 → REBA | 10/16 |
| Must | 11개 판정 초안, 법 기준 경고, 사람 확인, 조사자 확정, 엑셀 보고서, 얼굴 모자이크 | 10/23 |
| Should | GPT 설명·조언, 수정 이력 | 10/23 (개발 동결) |
| Could | 법정 서식 자동 작성, 증상조사표, 근로자 안내문, 표본 수 도우미, 이전 조사 비교, 영상에서 사진 뽑기, 모델 비교 | 시간이 남으면 |

## 9. 성공 기준

**최종 발표에서 반드시 동작해야 하는 것:**

1. PC에 설치된 우리 프로그램에 작업 사진 여러 장을 올리면 관절이 그려진 사진과 REBA 점수가 나온다. 얼굴은 가려져 있다.
2. 하루 작업시간을 넣으면 11개 기준 판정 초안과 근거가 나오고, 법 기준에 걸리면 경고가 뜨며, 불확실한 칸은 "사람 확인"으로 표시된다.
3. 조사자가 확인·확정하면 엑셀 보고서가 나온다.
4. 정확도 숫자를 보여준다: MoveNet Lightning의 각도 오차와 속도, REBA 점수 일치율, 판정 일치율, 자동 확정 비율과 그중 오류율.

### 근거와 확인 상태

- 법적 우선순위 (구현도 이 순서): 산업안전보건법 제39조제1항제5호 → 산업안전보건기준에 관한 규칙 제12장 → 고용노동부고시 제2020-12호(국가법령정보센터에서 현행 확인, 2026-10-08) → 고용노동부 해설(고시 각 호의 '주', 자세 각도) → KOSHA GUIDE H-9-2022 → REBA(지침 부록 2의 평가도구)
- 이미 확인한 것 (2026-10-08, 이 PC):
  - MoveNet Lightning 한 장 5.2ms (Thunder 12.0ms). TensorFlow 예제 래퍼, 4스레드, 사진 읽기 제외, 이 PC
  - 머리 점(코·눈·귀)으로 얼굴을 모자이크하는 방식은 MoveNet에도 같은 점이 있다 (모델을 정하기 전 MediaPipe 시험에서 영상 150프레임 모두 가림, 모자이크 0.17ms)
  - 부담작업 판정 규칙이 KOSHA 예시 11개와 모두 일치
  - REBA 계산이 공식 워크시트로 손 계산한 값과 일치
- 아직 확인 못 한 것: 윈도우 프로그램 화면, 실제 재연 영상에서의 각도 오차와 판정 일치율
