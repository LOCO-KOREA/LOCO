## 1. 이 문서가 정하는 것

- 기능마다 **입력 → 처리 규칙 → 출력 → 예외 → 수용 기준**을 정한다.
- 정하지 않는 것: 화면 배치(화면설계서), 테이블과 컬럼 이름(ERD, 데이터 담당이 확정), 함수와 필드 형식(API 계약서). 이 문서의 입력 항목은 업무 용어로 적고, 이름은 ERD에서 정한다.
- 화면 번호 S01~S09는 requirements.md 7절과 같다.
- 규칙의 근거는 아래 순서를 따른다. 위 근거와 아래 근거가 다르면 위를 따른다.
  1. 산업안전보건법
  2. 산업안전보건기준에 관한 규칙 제12장 (이하 '규칙')
  3. 고용노동부고시 제2020-12호 (이하 '고시')
  4. 고용노동부 해설: 고시 각 호에 붙은 '주' (이하 '해설')
  5. KOSHA GUIDE H-9-2022 (이하 '지침')
  6. REBA 워크시트 (Hignett & McAtamney 2000 기반)
- 법과 해설에 근거가 없는 값은 **기술 파라미터(8절)**로 따로 적고, 법 기준처럼 쓰지 않는다.
- 해설의 확인 출처: 같은 값을 싣는 글 3건 — 이동경·김증호, 대한인간공학회지 29(4), 2010.8 · 이동경, 대한인간공학회 2011 춘계학술대회 P2.9 · 정진우(고용노동부 중부지방고용노동청 성남지청장), 『산업보건』 2014년 11월호 37~42쪽(각 호의 '주'와 각주). 고용노동부의 원 해설 문서는 공개 사이트에서 찾지 못했다(OI-09). 2004년 1월 『안전기술』의 구판 해설은 굽힘을 30°로 풀이해 현행 값(20°)과 다르다. 대조 기록은 법정서식_검증목록.md 6절과 8절.

## 3. 상태 정의

### 3.1 단위작업 분석 상태

| 상태 | 뜻 | 다음 상태 (조건) |
|---|---|---|
| 영상 없음 | 단위작업만 등록됨 | 분석 대기 (영상 선택) |
| 분석 대기 | 영상을 골랐고 분석 전 | 분석 중 (동의 확인 + 분석 시작) |
| 분석 중 | 관절 추출과 계산 중 | 분석 완료 / 분석 실패 (EX-04, EX-08) / 취소됨 (취소) |
| 분석 완료 | 결과가 있음 | 분석 대기 (영상을 바꿈) |
| 분석 실패 | 결과 없음. 이유를 보여 줌 | 분석 대기 (다시 시도 또는 영상을 바꿈) |
| 취소됨 | 결과를 저장하지 않음 | 분석 대기 |

### 3.2 판정 상태 (단위작업 × 호)

| 상태 | 뜻 | 확정 |
|---|---|---|
| 해당 (초안) | 계산 결과 기준 이상 | 할 수 있음 |
| 비해당 (초안) | 계산 결과 기준 미만, 또는 단기간·간헐 작업 | 할 수 있음 |
| 사람 확인 | 계산은 됐지만 결과를 믿기 어려움 (확신도, 해석 차이, 관절 미검출 등) | 조사자가 해당·비해당과 사유를 고르면 할 수 있음 |
| 입력 필요 | 판정에 필요한 입력값이 없음 | 할 수 없음. 입력하면 다시 계산 |
| 해당 (확정) / 비해당 (확정) | 조사자가 확정함 | — |

전이 규칙

1. 판정 순서: 부담작업 전제(BR-02) → 입력 확인 → 계산 → 확신도 → 해석 차이. 앞 단계에서 결론이 나면 뒤 단계는 보지 않는다.
2. 조사자가 초안과 다른 결과로 확정하거나 '사람 확인'을 확정하면 사유가 있어야 한다.
3. 확정한 뒤 그 호에 영향을 주는 입력값이나 각도 기준이 바뀌면 확정이 풀리고 초안으로 돌아간다. 수정 이력에 남긴다 (OI-11).
4. 확정 결과를 고칠 때도 사유가 있어야 하고 수정 이력에 남는다.

## 5. 기능 상세

### F01 조사 관리

#### F01-01 조사 만들기와 조사개요 입력

- **요구사항** FR-001 · **화면** S02 · **우선순위** Must
- **입력**

| 항목 | 필수 | 값 |
|---|---|---|
| 조사 구분 | 예 | 정기 · 수시 · 최초 |
| 수시 사유 | 수시일 때 | 근골격계질환자 발생 · 부담작업에 해당하는 새 작업이나 설비 도입 · 업무량과 작업공정 등 작업환경 변경 (여러 개 선택) |
| 조사일 | 예 | 날짜 |
| 조사자 이름 | 예 | 글자 |
| 부서, 작업공정명, 작업명 | 예 | 글자 |

- **처리 규칙**
  1. 필수 항목이 모두 있어야 저장한다.
  2. 조사 상태는 '작성 중'으로 시작한다.
  3. 조사자 이름은 이 조사의 수정 이력에서 '누가'로 쓴다 (F05-06).
- **출력**: 저장된 조사. 다음 화면은 S03
- **예외**: 필수 항목이 빠지면 그 칸에 "입력해 주세요"
- **수용 기준**
  - AC-01: 조사개요를 모두 입력해 저장하고 다시 열면 입력한 값이 그대로 있다.

#### F01-02 조사 저장, 목록, 다시 열기

- **요구사항** FR-002, NFR-010 · **화면** S01 · **우선순위** Must
- **처리 규칙**
  1. 입력과 분석 결과는 바뀔 때마다 PC에 저장한다 (자동 저장).
  2. 목록은 조사일 최신순으로 보여 주고, 조사 상태(작성 중·확정)를 함께 표시한다.
  3. 다시 열면 마지막 상태 그대로 열린다.
  4. 원본 영상은 복사하지 않고 위치만 기억한다. 영상이 옮겨졌으면 결과는 그대로 보여 주고, 다시 분석할 때만 영상 위치를 다시 고르게 한다.
- **수용 기준**
  - AC-02: 조사 2개를 만들고 프로그램을 껐다 켜면 목록에 2개가 있고 결과가 그대로 열린다.

#### F01-03 다음 정기조사 예정일

- **요구사항** FR-003 · **화면** S01 · **우선순위** Should
- **처리 규칙**
  1. 정기·최초 조사의 예정일 = 그 조사의 확정일 + 3년 (규칙 제657조).
  2. 수시조사는 예정일을 바꾸지 않는다.
- **수용 기준**
  - AC-03: 2026-10-30에 확정한 정기조사 → 다음 정기조사 예정일 2029-10-30

### F04 자세 분석

#### F04-01 관절 추출

- **요구사항** FR-012 · **화면** 내부 · **우선순위** Must
- **처리 규칙**
  1. 매 프레임에서 관절 17개(코, 눈 2, 귀 2, 어깨 2, 팔꿈치 2, 손목 2, 엉덩이 2, 무릎 2, 발목 2)의 위치와 신뢰도를 뽑는다.
  2. 모델은 바꿔 끼울 수 있어야 하고, 기능은 이 17개만 쓴다.
  3. 신뢰도가 TP-02보다 낮은 점은 '안 보임'으로 둔다.
  4. 사람이 여러 명이면 EX-05를 따른다.
  5. 관절 위치 원자료는 메모리에서만 쓰고, 저장 범위는 데이터 설계에서 정한다 (OI-12).
- **수용 기준**
  - AC-11: 모델 두 개로 같은 영상을 돌려 둘 다 결과가 나온다.

#### F04-02 얼굴 모자이크

- **요구사항** FR-013 · **화면** S05, S06 · **우선순위** Must
- **처리 규칙**
  1. 머리 관절 점(코, 눈, 귀)으로 머리 상자를 만들어 모자이크한다.
  2. 머리 점이 안 보이면 직전 상자를 TP-11 프레임 동안 유지하고, 그래도 없으면 프레임 전체를 흐리게 한다.
  3. 화면, 대표 장면, 엑셀 이미지, 저장 파일에는 모자이크한 장면만 쓴다.
  4. 원본 영상 파일은 바꾸지 않는다.
- **수용 기준**
  - AC-12: 결과 화면과 엑셀 어디에도 얼굴이 보이지 않는다 (시험: 150프레임 모두 가림, 프레임당 20ms).

#### F04-03 관절 각도 계산

- **요구사항** FR-014 · **화면** S06 · **우선순위** Must
- **처리 규칙**: 프레임마다 왼쪽·오른쪽을 따로 계산한다. 기준 수직선은 화면 세로선이다.

| 각도 | 계산 | 쓰는 곳 |
|---|---|---|
| 몸통 기울기 (수직 기준) | 엉덩이 중점 → 어깨 중점 선이 수직선과 이루는 각. 앞으로 숙이면 +, 뒤로 젖히면 − | 4호 허리, REBA 몸통 |
| 목 기울기 (수직 기준) | 어깨 → 귀 선이 수직선과 이루는 각 | 4호 목 |
| 목 굽힘 (몸통 기준) | 몸통 선과 목 선 사이의 각 | REBA 목 |
| 위팔 들림 (수직 기준) | 어깨 → 팔꿈치 선이 수직 아래 방향과 이루는 각 | 3호 팔꿈치 들기 |
| 위팔 굽힘 (몸통 기준) | 몸통 선과 위팔 사이의 각 | REBA 위팔 |
| 팔꿈치 굽힘 | 팔을 곧게 펴면 0° | REBA 아래팔 |
| 무릎 굽힘 | 다리를 곧게 펴면 0° | 5호, REBA 다리 |

  1. 4호와 3호는 해설대로 **수직 기준**으로 재고, REBA는 워크시트대로 **몸통 기준**으로 잰다. 같은 목이라도 두 각도가 다를 수 있다.
  2. 관절 떨림을 줄이려고 TP-09 평활화를 한다.
- **수용 기준**
  - AC-13: 각도기로 잰 재연 영상과 비교해 각도별 평균 오차를 낸다. 목표치는 10/17 기술 검토에서 정한다 (NFR-015).

#### F04-04 법 문구 자세 판별

- **요구사항** FR-016, FR-017 · **화면** S06 · **우선순위** Must
- **입력**: 프레임별 관절 점과 각도, 각도 기준 (F07-02)
- **처리 규칙**: 프레임마다 아래 자세에 해당하는지 판별한다.

| 호 | 법 문구의 자세 | 판별 | 기준 (출처) | 측정 |
|---|---|---|---|---|
| 3호 a | 머리 위에 손이 있음 | 손목이 머리 꼭대기보다 위 | 고시 문구. 머리 꼭대기 추정은 TP-04 | 영상 |
| 3호 b | 팔꿈치가 어깨 위에 있음 | 팔꿈치가 어깨보다 위 | 고시 문구 | 영상 |
| 3호 c | 팔꿈치를 몸통으로부터 듦 | 위팔 들림(수직 기준) ≥ 45°, 앞이나 옆으로 | 해설 3호 주1 | 영상 (옆으로 든 것은 정면 영상이 있어야 잼, OI-07) |
| 3호 d | 팔꿈치가 몸통 뒤쪽에 있음 | 옆에서 볼 때 팔꿈치가 몸통 선보다 뒤 | 고시 문구 | 영상 |
| 4호 a | 목 굽힘 | 목 기울기(수직 기준) ≥ 20° | 해설 4호 주3 | 영상 |
| 4호 b | 허리 굽힘 (앞) | 몸통 기울기 ≥ +20° | 해설 4호 주3 | 영상 |
| 4호 c | 허리 젖힘 (뒤) | 몸통 기울기 ≤ −20° | 해설 4호 주3 | 영상 |
| 4호 제외 | 무릎을 바닥에 댄 채 허리를 앞으로 굽힘, 바닥에 엎드림 | 허리 굽힘으로 세지 않음 | 해설 4호 주3 단서. 무릎 바닥 접촉은 TP-06 | 영상 + 사람 확인 |

| 5호 a | 쪼그려 앉기 | 무릎이 발끝보다 앞으로 나올 만큼 굽히고 발이 체중을 지탱 | 해설 5호 주1. 발끝 추정은 TP-05 | 영상 |

- **예외**: EX-05, EX-06
- **수용 기준**
  - AC-14: 허리를 25° 굽힌 프레임은 4호 허리 굽힘으로 세고, 15°는 세지 않는다.
  - AC-15: 무릎을 바닥에 댄 채 허리를 30° 굽힌 프레임은 허리 굽힘으로 세지 않는다.

#### F04-05 자세 비율과 하루 노출 시간

- **요구사항** FR-016 · **화면** S06 · **우선순위** Must
- **처리 규칙**
  1. 자세 비율 = 그 자세에 해당하는 프레임 수 ÷ 분석 구간 프레임 수
  2. 하루 노출 시간 = 자세 비율 × 하루 작업시간 (BR-05)
  3. 3호는 a~d 중 하나라도 해당하는 프레임을 한 번만 센다 (BR-07).
  4. 4호와 5호는 자세별로 따로 계산하고, 합친 값도 함께 계산한다 (OI-01).
  5. 화면에는 시간을 소수 둘째 자리까지 보여 주고, 판정은 반올림하기 전 값으로 한다.
- **수용 기준**
  - AC-16: 허리 굽힘 비율 35%, 하루 작업시간 6시간 → 하루 노출 2.10시간
  - AC-17: 3호에서 a만 해당 20%, b만 해당 10%, a와 b 동시 10% → 3호 비율 40%. 동시 구간은 한 번만 센다.

#### F04-06 REBA 계산

- **요구사항** FR-018, FR-019 · **화면** S06 · **우선순위** Must
- **처리 규칙**
  1. 프레임마다 REBA 워크시트 13단계대로 계산한다.

| 단계 | 항목 | 점수 | 값을 얻는 곳 |
|---|---|---|---|
| 1 | 목 (몸통 기준) | 0~20° 굽힘 1, 20° 넘는 굽힘 또는 젖힘 2 | 영상 |
| 1a | 목 비틀림, 옆으로 굽힘 | 각각 +1 | 조사자 |
| 2 | 몸통 | 똑바름 1, 0~20° 굽힘·젖힘 2, 20~60° 굽힘 또는 20° 넘는 젖힘 3, 60° 넘는 굽힘 4 | 영상 |
| 2a | 몸통 비틀림, 옆으로 굽힘 | 각각 +1 | 조사자 |
| 3 | 다리 | 양발 지지 1, 한 발 지지·불안정 2. 무릎 굽힘 30~60° +1, 60° 넘음 +2 | 영상 (지지 상태는 조사자 확인) |
| 4 | 표 A | 1~3으로 조회 | 계산 |
| 5 | 하중 | 5kg 미만 0, 5~10kg +1, 10kg 넘음 +2. 충격이나 급격한 힘 +1 | 조사자 |
| 6 | 점수 A | 4 + 5 | 계산 |
| 7 | 위팔 (몸통 기준) | 20° 젖힘~20° 굽힘 1, 20° 넘는 젖힘 또는 20~45° 굽힘 2, 45~90° 3, 90° 넘음 4 | 영상 |
| 7a | 어깨 올림 +1, 위팔 벌림 +1, 팔을 받치거나 기댐 −1 | | 조사자 (벌림은 정면 영상이 있어야 잼) |
| 8 | 아래팔 | 팔꿈치 굽힘 60~100° 1, 그 밖 2 | 영상 |
| 9 | 손목 | 0~15° 1, 15° 넘음 2. 꺾임·비틀림 +1 | 조사자 (영상 정확도가 낮음) |
| 10 | 표 B | 7~9로 조회 | 계산 |
| 11 | 손잡이 | 좋음 0, 보통 +1, 나쁨 +2, 받아들일 수 없음 +3 | 조사자 |
| 12 | 점수 B, 표 C | 점수 B = 10 + 11. 점수 A·B로 표 C 조회 | 계산 |
| 13 | 활동 | 1분 넘게 정적 자세 +1, 분당 4회 넘는 작은 반복 +1, 급격한 큰 자세 변화나 불안정 +1 | 조사자 (영상이 1분보다 짧으면 정적 여부를 영상으로 알 수 없음) |

  2. REBA 점수 = 표 C 점수 + 활동 점수 (1~15). 위험 단계: 1 무시, 2~3 낮음, 4~7 보통, 8~10 높음, 11~15 매우 높음 (워크시트 Scoring).
  3. 좌우 중 점수가 높은 쪽을 쓴다 (TP-10).
  4. 하중은 원 논문의 kg 구간을 쓴다. 워크시트의 파운드 구간과 같다 (11파운드 ≈ 5kg, 22파운드 ≈ 10kg).
  5. 조사자 입력 항목이 비어 있으면 그 칸을 '사람 확인'으로 표시하고, 빈 칸을 0으로 둔 '임시 점수'를 보여 준다.
  6. REBA는 위험 정도만 보여 준다. 판정과 경고에는 쓰지 않는다 (BR-15).
- **수용 기준**
  - AC-18: KOSHA 지침의 '휠 들어올리기' 예시를 워크시트로 손 계산한 8점과 같다 (계산기로 확인함).
  - AC-19: 손목을 입력하기 전에는 손목 칸이 '사람 확인'이고, 입력하면 표시가 바뀐다.

#### F04-07 대표 장면

- **처리 규칙**
  1. REBA 점수가 가장 높은 프레임을 대표 장면으로 고른다. 점수가 같으면 먼저 나온 프레임이다.
  2. 조사자가 다른 프레임을 고르면 그 프레임의 REBA를 보여 주고 수정 이력에 남긴다.
  3. 대표 장면 이미지는 모자이크한 것만 저장한다.
- **수용 기준**
  - AC-20: 대표 장면을 바꾸면 REBA 점수가 다시 계산되고 이력에 한 줄이 남는다.

### F05 판정과 경고

#### F05-01 11개 기준 판정 초안

- **요구사항** FR-020 · **화면** S07 · **우선순위** Must
- **처리 규칙**
  1. 작업 기간 구분이 단기간작업이나 간헐적인 작업이면 11개 호를 모두 비해당으로 둔다 (BR-02).
  2. 호별로 아래 조건을 계산한다. 필요한 입력값이 없으면 '입력 필요'다.

| 호 | 고시 제3조 조건 (요약) | 계산 | 해설 |

| 1 | 하루 4시간 이상 집중적으로 자료입력 등을 위해 키보드·마우스 조작 | 집중 입력 시간 ≥ 4. 근로자가 입력 시간을 마음대로 조절할 수 있으면 비해당 | 1호 주1~4, 각주 3·4 |

| 3 | 하루 총 2시간 이상 손이 머리 위, 팔꿈치가 어깨 위, 팔꿈치를 몸통에서 듦, 팔꿈치가 몸통 뒤 | 3호 하루 노출(합산) ≥ 2 | 3호 주1·2 |

#### F05-02 확신도와 사람 확인

- **요구사항** FR-023 · **화면** S06, S07 · **우선순위** Must
- **처리 규칙**
  1. 영상으로 계산하는 호(3·4·5호)는 측정 각도를 −5°, 그대로, +5°로 바꿔 세 번 판정한다 (TP-01).
  2. 세 결과의 해당·비해당이 다르면 '사람 확인'이다. 사유: "기준 각도 근처 자세가 많음"
  3. 그 밖의 사람 확인 사유
     - 판별 불가 프레임 비율이 TP-03을 넘음
     - 자세별로 따로 본 결과와 합친 결과가 다름 (OI-01)
     - 여러 사람이 찍힘 (EX-05), 다리가 화면에서 잘림 (EX-06)
     - 4호 제외 자세(무릎을 바닥에 댄 굽힘)로 판별된 프레임이 있음
  4. REBA는 각도를 흔들어 위험 단계가 바뀌면 그 부위 점수에 '사람 확인'을 표시한다.
- **수용 기준**
  - AC-24: 허리 각도가 20° 근처에 몰린 영상에서 −5°로는 비해당, +5°로는 해당이 되면 4호가 '사람 확인'으로 나온다.

#### F05-03 경고

- **요구사항** FR-021, FR-028 · **화면** S06 · **우선순위** Must
- **처리 규칙**

  2. '사람 확인'인 호는 경고 대신 "확인 필요"로 표시한다.
  3. 경고 기본 문구: "부담작업 {N}호 기준({기준 요약})을 넘습니다."
  4. GPT 조언은 F06-02가 덧붙인다. GPT가 없어도 경고는 뜬다.
  5. 경고는 경고 기록에 남는다.
- **수용 기준**
  - AC-25: 허리 굽힘 35% × 하루 6시간이면 "부담작업 4호 기준(하루 총 2시간)을 넘습니다"가 뜬다. 인터넷을 끊어도 뜬다.

  2. 다시 계산은 저장된 프레임별 각도로 한다. 영상을 다시 분석하지 않는다 (OI-12).
  3. 확정된 호가 영향을 받으면 확정이 풀린다 (3.2절 규칙 3).

#### F05-05 확인, 수정, 확정

- **요구사항** FR-024 · **화면** S07 · **우선순위** Must

  3. '입력 필요'가 있는 호는 확정할 수 없다.
  4. '사람 확인'인 호는 조사자가 해당·비해당과 사유를 고르면 확정된다.
  5. 단위작업 전체를 확정할 때 '사람 확인'이 남아 있으면 먼저 경고한다.

  - AC-27: '입력 필요'인 호는 확정 버튼이 꺼져 있다. '사람 확인'은 사유 없이 확정되지 않는다.

### F06 보고서와 설명

#### F06-02 GPT 문장

- **요구사항** FR-027, NFR-011 · **화면** S06, S08 · **우선순위** Should
- **보낼 수 있는 값** (이것만 보낸다): 호 번호, 기준 요약, 고시 제3조 원문 문구 (공개 법령. GPT가 쓴 법 기준 숫자를 검사하려고 보냄), 하루 노출 시간, 하루 작업시간, 자세 비율, REBA 점수와 부위 점수와 위험 단계, 무게와 횟수 숫자
- **보내지 않는 값**: 영상과 이미지, 사람·회사·부서 이름, 작업명 같은 자유 입력 글 (OI-05)
- **처리 규칙**
  1. 경고 조언은 1~3문장, 보고서 요약은 3~5문장으로 받는다.
  2. 받은 문장은 "AI 작성"으로 표시하고, 조사자가 고칠 수 있다.
  3. 받은 문장에 보낸 적 없는 숫자가 있으면 버리고 기본 문구를 쓴다 (BR-21).
  4. GPT는 판정과 점수를 바꾸지 않는다. 문장만 쓴다.
- **수용 기준**
  - AC-30: 보낸 요청 기록에 영상과 이름이 없다.
  - AC-31: 받은 문장에 보내지 않은 숫자가 있으면 기본 문구가 나온다.

#### F06-03 GPT 없이 기본 문구

- **요구사항** FR-028, NFR-012 · **화면** S06 · **우선순위** Must
- **처리 규칙**: 키가 없거나, 인터넷이 없거나, 시간이 초과되거나(TP-08), 오류가 나거나, 숫자가 맞지 않으면 기본 문구를 쓴다. 점수, 판정, 경고, 엑셀은 그대로 동작한다.
- **예외**: EX-10, EX-11
- **수용 기준**
  - AC-32: 인터넷을 끊고 분석부터 엑셀 저장까지 할 수 있다.

### F07 설정과 모델

#### F07-01 관절 모델 선택

#### F07-02 각도 기준 보기와 변경

- **요구사항** FR-017, FR-030 · **화면** S09 · **우선순위** Must
- **표시**

| 기준 | 기본값 | 출처 |
|---|---|---|
| 목 굽힘 (수직 기준) | 20° | 해설 4호 주3 |
| 허리 굽힘 (앞) | 20° | 해설 4호 주3 |
| 허리 젖힘 (뒤) | 20° | 해설 4호 주3 |
| 목 비틀림 | 5° (조사자가 판단할 때 쓰는 안내) | 해설 4호 주4 |
| 허리 비틀림 | 20° (조사자가 판단할 때 쓰는 안내) | 해설 4호 주4 |
| 팔꿈치 들기 (위팔, 수직 기준) | 45° | 해설 3호 주1 |
| 쪼그려 앉기 | 무릎이 발끝보다 앞 (각도가 아님) | 해설 5호 주1 |

- **처리 규칙**
  1. 기본값은 앱 설정에 두고, 바꾼 값은 그 조사에만 적용한다. 다른 조사로 퍼지지 않게 한다.
  2. 바꾸려면 사유가 있어야 한다 (해설의 "특별한 사정이 없는 한").
  3. 바꾼 값은 화면과 엑셀에 "조사자 변경 (사유)"으로 표시한다.
  4. '기본값으로 되돌리기'를 둔다.
  5. 바꾸면 수정 이력에 남기고 F05-04로 다시 계산한다.
- **수용 기준**
  - AC-34: 사유 없이 바꾸면 저장되지 않는다. 사유를 넣으면 저장되고, 이력에 한 줄이 남고, 엑셀에 "조사자 변경"이 표시된다.

- **처리 규칙**

  2. 키는 이 PC에만 저장하고, 보관 방법은 API 계약서에서 정한다.
- **수용 기준**
  - AC-35: GPT 사용을 끄면 기본 문구만 나온다.
