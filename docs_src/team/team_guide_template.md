## 1. 한 문단으로

우리 앱은 **PC 프로그램**입니다. 조사자가 작업 중에 찍은 **사진 여러 장**을 올리고 하루 작업시간을 넣으면, 사진에서 자세를 재서 "허리를 20° 이상 굽힌 사진이 몇 장 중 몇 장인지"로 시간 비율을 구하고, "허리를 굽힌 시간이 하루 몇 시간인지"를 계산합니다. 그리고 고시 제3조의 **부담작업 11개 기준**에 걸리는지 **초안**을 냅니다. 확정은 사람이 하고, 결과는 엑셀로 나옵니다. 관절은 MoveNet Lightning으로 찾습니다.

예: 사진 20장 중 7장에서 허리를 굽힘(35%), 하루 작업시간 6시간 → 하루 2.10시간 → 4호 기준(하루 총 2시간)을 넘으므로 경고.

## 2. 하지 않는 것

- **진단하지 않는다.** 근골격계질환이 있다 없다를 말하지 않는다. 법 기준에 해당하는지 초안만 낸다.
- **GPT는 문장만 쓴다.** 판정, 점수, 경고는 GPT가 아니라 규칙이 정한다. GPT로는 숫자와 법 문구만 나가고, 사진·이미지·이름은 나가지 않는다.
- **원본 사진은 복사하지 않는다.** 원본 사진은 사용자 폴더에 그대로 두고, 앱이 저장하는 사진은 분석마다 대표 사진 1장뿐이다.
- **법에 없는 기준을 만들지 않는다.** 각도는 고용노동부 해설 값을 쓰고 출처를 보여 준다. 바꾸려면 사유를 적고 이력에 남는다.
